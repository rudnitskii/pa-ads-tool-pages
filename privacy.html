Privacy Policy

Last updated: 2026-09-12

This Privacy Policy describes how the PA Google Ads Audit Tool ("the application") accesses and handles data. The application is an internal tool used exclusively by PA performance marketing agency to manage and report on its own client advertising accounts.

Data we access

The application uses the Google Ads API (OAuth scope: https://www.googleapis.com/auth/adwords) to read advertising performance metrics (impressions, clicks, cost, conversions) from Google Ads accounts that the authorized user manages or has been granted access to.

How we use the data

Data retrieved via the API is used solely for internal reporting, auditing, and campaign optimization purposes on behalf of the accounts' owners. It is not sold, shared with third parties, or used for any purpose other than the operation of this internal tool.

Data storage

Data is processed locally and is not stored on any public or third-party server beyond what is required for generating internal reports.
